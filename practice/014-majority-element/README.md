# 014 · Majority element

*Easy · aim for 15 minutes*

Given an array `nums` of length n, return the value that appears more than n / 2 times. Such a value is guaranteed to exist.

| Input | Output | Why |
| --- | --- | --- |
| `nums = [3, 2, 3]` | `3` | 3 appears twice out of three |
| `nums = [2, 2, 1, 1, 1, 2, 2]` | `2` | 2 appears four times out of seven |
| `nums = [7]` | `7` | a single element is its own majority |

**Constraints**

- `1 <= nums.length <= 200000`
- `-1000000000 <= nums[i] <= 1000000000`
