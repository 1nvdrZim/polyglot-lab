# 016 · Climbing stairs

*Easy · aim for 15 minutes*

You are climbing a staircase with `steps` steps. Each move takes you up either 1 step or 2 steps. Return the number of distinct ways to reach the top.

| Input | Output | Why |
| --- | --- | --- |
| `steps = 1` | `1` | one single step |
| `steps = 2` | `2` | 1 + 1, or 2 |
| `steps = 3` | `3` | 1 + 1 + 1, 1 + 2, or 2 + 1 |
| `steps = 5` | `8` | there are eight different orders |

**Constraints**

- `1 <= steps <= 45`
