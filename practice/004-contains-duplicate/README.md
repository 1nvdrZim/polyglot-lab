# 004 · Contains duplicate

*Easy · aim for 15 minutes*

Given an array of integers `nums`, return true if any value appears at least twice, and false if every value is distinct.

| Input | Output | Why |
| --- | --- | --- |
| `nums = [1, 2, 3, 1]` | `true` | 1 appears twice |
| `nums = [1, 2, 3, 4]` | `false` | every value is distinct |
| `nums = []` | `false` | an empty array has no duplicates |

**Constraints**

- `0 <= nums.length <= 200000`
- `-1000000000 <= nums[i] <= 1000000000`
